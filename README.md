# Automatic Waste Classification Using Deep Learning

## SE4050 – Deep Learning 2026

This project develops and evaluates deep learning models for automatic
waste classification using a real-world image dataset.

The project compares four distinct deep learning architectures under
controlled experimental conditions.

## Problem

Manual waste sorting is time-consuming and can lead to incorrect
classification of recyclable and non-recyclable materials.

This project investigates whether deep learning can automatically
classify waste images into predefined waste categories.

## Objectives

1. Select and preprocess a suitable real-world waste image dataset.
2. Perform exploratory data analysis.
3. Develop four distinct deep learning architectures.
4. Train and evaluate the models under comparable conditions.
5. Compare predictive performance, computational efficiency,
   model complexity and generalization.
6. Identify limitations and possible improvements.
